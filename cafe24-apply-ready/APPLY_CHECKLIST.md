# 페르패키지 Cafe24 1차 적용 QA 체크리스트

## 공통

- [ ] 기존 Cafe24 스킨 파일을 백업했다.
- [ ] 테스트 스킨 또는 복사 스킨에서 먼저 적용했다.
- [ ] PC 화면에서 레이아웃이 깨지지 않는다.
- [ ] 모바일 390px에서 가로 스크롤이 생기지 않는다.
- [ ] 브라우저 콘솔 오류가 없다.
- [ ] 기존 Cafe24 헤더/푸터가 깨지지 않는다.
- [ ] 공통 CSS가 상품목록, 게시판, 마이쇼핑, 장바구니 기본 기능을 망가뜨리지 않는다.
- [ ] 고객 화면에 `TODO`, `placeholder`, `미구현`, `테스트` 문구가 보이지 않는다.
- [ ] 관리자 URL 패턴이 고객 화면에 노출되지 않는다.
- [ ] 확정 견적, 즉시 제작, 결제 확정처럼 보이는 문구가 없다.

## 메인/고객센터/가이드

- [ ] 메인 스니펫이 본문 영역에 정상 표시된다.
- [ ] 고객센터 스니펫이 정상 표시된다.
- [ ] 제작가이드 링크가 정상 이동한다.
- [ ] 디자인가이드 링크가 정상 이동한다.
- [ ] 제작주의사항 링크가 정상 이동한다.
- [ ] 상담 CTA 링크가 운영 흐름에 맞게 이동한다.
- [ ] 모바일에서 카드와 버튼 텍스트가 겹치지 않는다.

## 마이쇼핑

- [ ] 로그아웃 상태에서 `/myshop/index.html`에 접속했다.
- [ ] 로그아웃 상태에서 마이쇼핑 본문이 바로 노출되지 않는다.
- [ ] 로그아웃 상태에서 로그인 안내 화면만 보인다.
- [ ] 로그아웃 상태 페이지 소스에 회원명/주문정보/적립금 값이 렌더링되지 않는다.
- [ ] `로그인하기` 버튼이 `/member/login.html?returnUrl=%2Fmyshop%2Findex.html`로 이동한다.
- [ ] `비회원 주문조회` 버튼이 `/member/login.html?noMemberOrder&returnUrl=%2Fmyshop%2Forder%2Flist.html`로 이동한다.
- [ ] 로그인 후 `/myshop/index.html`에 접속하면 회원명이 표시된다.
- [ ] 로그인 후 회원등급이 표시된다.
- [ ] 로그인 후 주문처리현황 카운트가 표시된다.
- [ ] 주문조회 링크가 정상 이동한다.
- [ ] 회원정보 링크가 정상 이동한다.
- [ ] 배송 주소록 링크가 정상 이동한다.
- [ ] 1:1 맞춤상담 링크가 정상 이동한다.
- [ ] 대량구매 문의 관리 링크가 정상 이동한다.

## 장바구니

- [ ] 장바구니가 비어 있을 때 안내 문구가 정상 표시된다.
- [ ] 상품을 담은 상태에서 상품명이 정상 표시된다.
- [ ] 상품 썸네일이 정상 표시된다.
- [ ] 수량 증가/감소가 정상 동작한다.
- [ ] 수량 변경 버튼이 정상 동작한다.
- [ ] 옵션 변경 레이어가 정상 동작한다.
- [ ] 선택 삭제가 정상 동작한다.
- [ ] 관심상품 이동이 정상 동작한다.
- [ ] 선택 상품 진행이 정상 동작한다.
- [ ] 전체 상품 진행이 정상 동작한다.
- [ ] 총 상품금액/배송비/합계가 정상 표시된다.
- [ ] 하단 고정 버튼이 본문을 가리지 않는다.
- [ ] 모바일에서 상품 카드와 버튼이 화면 밖으로 넘치지 않는다.

## 최종 확인

- [ ] 실제 운영 도메인에서 상대경로가 정상 동작한다.
- [ ] Cafe24 module 오류가 없다.
- [ ] Cafe24 기본 주문/회원/게시판 기능이 정상이다.
- [ ] 문제 발생 시 즉시 백업본으로 되돌릴 수 있다.
