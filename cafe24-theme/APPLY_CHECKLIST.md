# Cafe24 테마 적용 체크리스트

## 적용 전

- [ ] 운영 스킨이 아닌 복사 스킨을 준비했다.
- [ ] 기존 `layout.html`, `main.html`, `index.html`, `product/list.html`을 백업했다.
- [ ] 기존 레이아웃의 앱, 결제, 채널, 분석 스크립트 import를 확인했다.
- [ ] `cate_no`가 현재 Cafe24 관리자 상품분류 번호와 일치한다.
- [ ] 회사 정보와 개인정보관리책임자 정보가 Cafe24 관리자에 등록되어 있다.

## 공통 레이아웃

- [ ] 모든 페이지에서 헤더와 푸터가 한 번만 표시된다.
- [ ] `<!--@contents-->` 위치에 본문이 정상 삽입된다.
- [ ] 로그인 상태에서 마이페이지와 로그아웃 링크가 표시된다.
- [ ] 로그아웃 상태에서 로그인과 회원가입 링크가 표시된다.
- [ ] 검색어 입력 후 Cafe24 상품검색 결과로 이동한다.
- [ ] 장바구니 수량이 Cafe24 값과 일치한다.
- [ ] 관리자에서 상품분류 순서를 바꾸면 헤더 메뉴에 반영된다.
- [ ] 헤더 바로가기 아이콘 5개가 깨진 이미지 없이 표시된다.
- [ ] `config.js`의 패키지 상위분류가 운영값 `cate_no=44`와 일치한다.

## 메인

- [ ] 배너 이전·다음 버튼이 동작한다.
- [ ] 신상품 진열 `product_listmain_2`가 표시된다.
- [ ] 추천상품 진열 `product_listmain_1`이 표시된다.
- [ ] 상품명, 가격, 아이콘, 장바구니 버튼이 정상이다.
- [ ] 상품 클릭 시 `/product/detail.html{$param}`으로 이동한다.
- [ ] 메인 하단 Pluuug 견적문의 iframe이 표시된다.
- [ ] 견적문의 CTA가 Pluuug 폼을 새 탭으로 연다.
- [ ] 주요 서비스 아이콘 8개가 기존 Vercel 디자인과 같은 이미지로 표시된다.

## 상품분류

- [ ] 카테고리 상단에 중앙 롤링배너와 양옆 배너 미리보기가 표시된다.
- [ ] 이전, 다음, 일시정지 버튼과 현재 배너 번호가 정상 작동한다.
- [ ] `cate_no`를 바꾸면 배너 문구, 추천 용도, 상담 준비사항과 상품 제목이 해당 분류에 맞게 바뀐다.
- [ ] 키보드 좌우 방향키로 배너를 이동할 수 있고 포커스 중에는 자동 전환이 멈춘다.
- [ ] 하위 카테고리와 상품 수가 정상이다.
- [ ] 정렬 링크가 정상 동작한다.
- [ ] 상품비교 기능을 사용하는 경우 정상 동작한다.
- [ ] 상품목록 페이징이 정상 동작한다.
- [ ] 단상자 분류(`cate_no=65`)에서 구조 비교, 재질·후가공, 제작 순서, FAQ가 표시된다.
- [ ] 단상자 이외 분류에서는 단상자 상세 콘텐츠가 표시되지 않는다.
- [ ] 단상자 분류(`cate_no=65`)에서 구조 비교, 재질·후가공, 제작 순서, FAQ가 표시된다.
- [ ] 단상자 이외 분류에서는 단상자 상세 콘텐츠가 표시되지 않는다.

## 안내 페이지

- [ ] 고객센터, FAQ, 제작가이드, 디자인가이드, 주의사항이 열린다.
- [ ] 안내 페이지에서도 공통 헤더·푸터·퀵메뉴가 표시된다.
- [ ] 견적문의, 상품 Q&A, 마이페이지 링크가 정상이다.

## 반응형·접근성

- [ ] 1440px에서 헤더, 배너, 상품 4열이 정상이다.
- [ ] 390px에서 가로 스크롤이 생기지 않는다.
- [ ] 모바일 검색과 전체 메뉴 버튼이 동작한다.
- [ ] 모바일 하단 퀵바가 본문 버튼을 가리지 않는다.
- [ ] PC 우측 퀵메뉴와 모바일 하단 퀵바 아이콘이 정상 표시된다.
- [ ] 키보드로 링크와 버튼에 접근할 수 있다.
- [ ] 브라우저 콘솔 오류가 없다.

## 운영 기능 회귀

- [ ] 상품 옵션 선택이 정상이다.
- [ ] 장바구니 담기가 정상이다.
- [ ] 로그인과 로그아웃이 정상이다.
- [ ] 주문서와 결제 화면이 기존과 동일하게 동작한다.
- [ ] 마이페이지 주문조회가 정상이다.
- [ ] 파일 업로드와 재업로드 기능이 정상이다.

## 배포 전

- [ ] 테스트 스킨에서 PC와 모바일 실제 주문을 1회 완료했다.
- [ ] 개인정보 또는 관리자 전용 값이 고객 화면에 노출되지 않는다.
- [ ] 운영 스킨으로 반영할 파일 목록을 다시 확인했다.
- [ ] 문제가 생기면 즉시 복구할 백업본이 있다.
