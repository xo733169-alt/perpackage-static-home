# 페르패키지 support.html 즉시 반영 가능 범위 보강 보고서

작성일: 2026-06-25

## 1. 수정한 파일

- `perpackage-vercel-public/support.html`
- `perpackage-vercel-public/perpackage-main-renewal.css`

## 2. 지금 바로 반영한 영역

### 고객센터 허브 구조

좌측 메뉴를 고객이 바로 찾기 쉬운 고객센터 허브 중심으로 재정리했습니다.

- FAQ
- 제작가이드
- 디자인가이드
- 제작주의사항
- 배송/납품 안내
- 서류 안내
- 견적문의 연결

### 마이페르패키지 안내형 대시보드

실제 회원/주문 데이터 없이도 고객이 다음 행동을 이해할 수 있도록 안내형 카드로 변경했습니다.

- 나의 견적문의
- 상담 진행중
- 제작 진행중
- 납품/배송 완료
- 서류 요청
- 재견적 요청

기존처럼 실제 데이터가 필요한 숫자형 회원·주문 항목은 고객 화면에서 제거했습니다.

### 주문·제작 진행 안내

페르패키지 맞춤제작 흐름에 맞춰 6단계 제작 안내를 추가했습니다.

- 문의접수
- 사양확인
- 견적안내
- 디자인/칼선 확인
- 제작진행
- 납품/배송

안내 문구로 `최종 견적과 납기는 사양 확인 후 안내됩니다.`를 유지했습니다.

### 결제·서류 안내

실제 발급 기능을 만들지 않고 안내형 카드로만 구성했습니다.

- 세금계산서 안내
- 거래명세서 안내
- 현금영수증 안내
- 사업자등록증
- 통장사본
- 가상계좌 안내
- 환불계좌 안내

문서 링크는 기존 운영 준비 경로를 유지했습니다.

- 사업자등록증: `assets/documents/perpackage-business-registration-2026.pdf`
- 통장사본: `assets/documents/perpackage-bankbook-copy.png`

### 주문·배송 조회 안내

실제 주문조회 기능 없이 고객 안내형 카드로 정리했습니다.

- 주문/배송 조회
- 결제대기 내역
- 제작 진행 현황
- 재견적 요청
- 취소/변경 문의

### 문의 유형 선택

고객이 어떤 문의를 해야 할지 고를 수 있도록 8개 카드형 링크를 추가했습니다.

- 견적문의: `index.html#quote`
- 패키지 종류 상담: `category.html?category=box`
- 디자인 파일 문의: `faq.html`
- 로고 인쇄 상담: `category.html?category=logo-print`
- 소량·샘플 제작: `category.html?category=small-sample`
- 배송·납품 문의: `support.html#support-delivery`
- 서류 문의: `support.html#support-documents`
- FAQ 보기: `faq.html`

## 3. 카페24 확인 후 반영해야 하는 영역

- 회원 로그인/회원정보 수정 연결
- 주문조회 및 주문 상태 모듈 연결
- 주문/배송 상세 내역 연결
- 세금계산서, 거래명세서, 현금영수증 발행 프로세스 확정
- 가상계좌 및 환불계좌 운영 방식 확정
- 고객 문의내역 또는 게시판 URL 확정
- 실제 카카오톡 또는 ChannelTalk 상담 URL 확정
- Cafe24 공지 게시판, 상품 Q&A 게시판 고객용 URL 확정

## 4. 고객 화면에 노출하지 않은 TODO 항목

아래 내용은 HTML 주석으로만 남겼고 고객 화면의 본문 텍스트에는 노출되지 않도록 확인했습니다.

- Cafe24 마이쇼핑 문의/주문조회 모듈 연결
- Cafe24 주문조회 모듈 연결 시 실제 주문 상태와 분리 표시 검토
- 세금계산서 발급 프로세스 연결
- 가상계좌/환불계좌 등록 기능 연결
- 공지 게시판 및 상품 Q&A 게시판 URL 교체
- 카카오톡 또는 ChannelTalk 실제 URL 교체
- 개인정보처리방침 운영 URL 교체

## 5. support.html 디자인 보강 내용

- 기존 좌측 메뉴 + 우측 콘텐츠 구조는 유지했습니다.
- 실제 데이터처럼 보일 수 있는 숫자형 마이쇼핑 영역을 안내형 카드로 전환했습니다.
- 제작 흐름, 서류 안내, 주문·배송 조회 안내, 문의 유형 선택을 카드형 구조로 추가했습니다.
- 기존 페르패키지 톤인 흰색, 남색, 연회색 중심으로 스타일을 맞췄습니다.
- 모바일에서는 카드가 1열로 자연스럽게 내려가도록 CSS를 보강했습니다.
