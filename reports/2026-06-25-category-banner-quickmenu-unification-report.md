# 페르패키지 카테고리 배너·퀵메뉴·공통 UI 정리 보고서

작성일: 2026-06-25

## 1. 수정한 파일 목록

- `index.html`
- `category.html`
- `product.html`
- `perpackage-main-renewal.css`
- `perpackage-category.js`
- `perpackage-common.js`

## 2. 퀵메뉴 위치 조정 내용

- 우측 고정 퀵메뉴의 PC 위치 기준을 더 오른쪽 여백에 붙는 방향으로 조정했습니다.
- 공통 CSS의 `.perpackage-floating-quick` 위치를 변경했습니다.
- 공통 CSS가 로드되지 않는 페이지를 위한 `perpackage-common.js` fallback 스타일도 같은 위치 기준으로 맞췄습니다.
- 1440px 중간 폭에서는 카테고리/상품 본문 오른쪽 여백을 추가해 퀵메뉴가 배너와 상품 영역을 덮지 않도록 보정했습니다.
- 모바일에서는 기존처럼 우측 세로 퀵메뉴를 숨기고 하단 고정 퀵바를 유지했습니다.

## 3. 제거한 아이콘형 링크 섹션 정리

- `index.html`의 헤더 아이콘 메뉴 마운트 영역을 제거했습니다.
- `index.html`의 메인 배너 하단 빠른 아이콘 메뉴 마운트 영역을 제거했습니다.
- `category.html`의 헤더 안에 있던 전체상품, 로고인쇄, 견적함, 제작가이드, 샘플·소량, 상담문의 아이콘 묶음을 제거했습니다.
- `product.html`의 동일한 헤더 아이콘 묶음을 제거했습니다.
- 공통 CSS에서도 `.pp-shop-icon-nav`, `.pp-shop-quick-menu`를 화면에 표시하지 않도록 정리했습니다.
- 상단 카테고리 네비게이션, 카테고리 탭, 카테고리 보조 태그, 공통 퀵메뉴는 유지했습니다.

## 4. 카테고리 추천배너 변경 내용

- 기존 작은 카드형 추천 배너를 대형 카테고리 롤배너 구조로 변경했습니다.
- `perpackage-category.js`의 `renderHeroSlider()` 렌더링을 3열 카드식이 아닌 1장 중심 슬라이드로 정리했습니다.
- 배너 내부는 대표 이미지 1장과 제목, 설명 중심으로 구성했습니다.
- 배너 안의 별도 버튼형 요소는 제거하고, 배너 전체가 링크 역할을 하도록 유지했습니다.
- 기존 카테고리 히어로는 카테고리명과 설명 중심으로 줄이고, 새 롤배너가 대표 비주얼 역할을 하도록 분리했습니다.
- `category.html`의 배너 영역 aria-label을 카테고리 상단 비주얼 용도로 정리했습니다.

## 5. 메인포털과 타 페이지 통일을 위해 손본 공통 요소

- 쇼핑몰형 헤더의 데스크톱 그리드를 3열 구조에서 로고와 검색창 중심의 2열 구조로 정리했습니다.
- 헤더 높이를 조금 줄여 카테고리, 상세, 메인 페이지 간 정렬감을 맞췄습니다.
- 카테고리/상품 페이지의 PC 본문 오른쪽 여백을 조정해 공통 퀵메뉴와 자연스럽게 공존하도록 했습니다.
- 카테고리 대형 롤배너의 라운드, 보더, 배경, 그림자, 제목 계층을 기존 페르패키지 톤에 맞춰 정리했습니다.
- 모바일에서는 기존 검색 버튼, 견적문의, 전체상품 접근, 하단 퀵바 흐름을 유지했습니다.

## 6. 기존 구조를 유지한 부분

- 견적문의 이동 흐름: `index.html#quote`
- 우측 고정 퀵메뉴와 모바일 하단 퀵바
- 상단 메인 네비게이션
- 카테고리 탭 구조
- 카테고리 보조 태그 구조
- 카테고리 검색, 필터, 정렬 기능
- 상품 상세 링크와 견적문의 연결
- FAQ, 고객센터, 제작가이드, 디자인가이드, 제작주의사항 링크 구조
- 사업자등록증, 통장사본 새 창 링크

## 7. 반응형 및 기능 검증 결과

검증 방식:

- Chrome headless CDP로 로컬 파일 URL 직접 로드
- JS 문법 검사: `perpackage-main-renewal.js`, `perpackage-category.js`, `perpackage-product.js`, `perpackage-common.js`
- 주요 페이지 렌더링, 가로 overflow, 콘솔 오류, 중복 아이콘 섹션 노출 여부 확인

검증 URL:

- `index.html`
- `category.html?category=shopping-bag`
- `category.html?category=shopping-bag&search=로고&print=로고인쇄상담`
- `product.html?category=box&product=basic-white-box`
- `product.html?category=shopping-bag&product=plain-shopping-bag`
- `faq.html`
- `support.html`
- `guide-production.html`
- `guide-design.html`
- `guide-caution.html`

확인 결과:

- PC 1440px: 가로 overflow 없음
- 모바일 390px: 가로 overflow 없음
- 중복 아이콘형 링크 섹션: 화면 노출 없음
- 우측 퀵메뉴: PC에서 표시, 모바일에서 하단 퀵바로 전환
- 카테고리 대형 배너: 1장 중심 배너 폭으로 렌더링
- 카테고리 배너와 퀵메뉴: 1440px에서 겹침 없음
- 콘솔 오류 없음
- 관리자 URL 노출 없음
- 고객 화면에 개발용 확인 문구 노출 없음
- 제한 문구 노출 없음

## 8. 다음 단계에서 더 다듬을 수 있는 부분

- 카테고리별 롤배너 이미지 비율을 통일하면 상단 완성도가 더 좋아집니다.
- 1920px 이상 넓은 화면에서 퀵메뉴 위치를 실제 모니터 기준으로 한 번 더 미세 조정하면 좋습니다.
- FAQ와 가이드 페이지도 추후 공통 헤더를 쇼핑몰형 헤더로 완전히 통합할지 결정할 수 있습니다.
- 카테고리 롤배너는 실제 운영 배너 이미지가 확정되면 이미지별 focal point를 별도로 잡는 것이 좋습니다.

## 9. 최종 작업 방향 한 줄 요약

퀵메뉴는 오른쪽 여백 기준으로 정리하고, 중복 아이콘 링크 묶음은 제거했으며, 카테고리 페이지의 작은 추천 배너를 1장 중심의 대형 카테고리 비주얼로 바꿔 전체 사이트 톤을 더 일관되게 맞췄습니다.
