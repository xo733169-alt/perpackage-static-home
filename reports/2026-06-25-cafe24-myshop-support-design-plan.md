# 페르패키지 고객센터/마이쇼핑 Cafe24 전환 디자인 메모

작성일: 2026-06-25

## 1. 작업 목적

`support.html`을 Cafe24 스마트디자인의 고객센터/마이쇼핑 모듈 삽입을 고려한 디자인 초안으로 정리했습니다.

이번 작업은 실제 로그인, 주문조회, 결제, 영수증, 쿠폰, 적립금 기능을 구현한 것이 아닙니다. 정적 홈페이지에서는 구조와 디자인 자리만 준비하고, 실제 데이터는 Cafe24 스마트디자인 모듈/변수로 대체하는 방향입니다.

## 2. support.html에서 Cafe24 모듈로 교체해야 할 영역

### 나의 쇼핑정보

교체 대상:

- 총적립금
- 사용적립금
- 가용적립금
- 쿠폰
- 총주문

현재 상태:

- 고객 화면에는 로그인 후 확인하는 정보처럼 보이도록 표시했습니다.
- HTML 주석으로 Cafe24 마이쇼핑 모듈/변수 교체 예정 위치를 남겼습니다.

### 나의 주문처리 현황

교체 대상:

- 입금전
- 배송준비중
- 배송중
- 배송완료
- 취소
- 교환
- 반품

현재 상태:

- 실제 수량 데이터는 표시하지 않았습니다.
- Cafe24 주문조회/주문처리 현황 모듈로 교체할 영역입니다.

### 마이쇼핑 바로가기

교체 대상:

- 주문조회
- 회원정보
- 관심상품
- 최근 본 상품
- 적립금
- 쿠폰
- 게시물관리
- 배송 주소록 관리
- 대량구매 문의 관리

현재 상태:

- 정적 페이지에서는 내부 안내 섹션 또는 상품/견적문의 흐름으로 연결했습니다.
- Cafe24 고객용 URL 확정 후 각 링크를 교체하면 됩니다.

## 3. 고객센터 링크 구성

좌측 고객센터 메뉴:

- 고객센터 연락처
- 상담 채널
- FAQ 카테고리
- 고객센터 메뉴

FAQ 카테고리:

- 회원관리
- 주문/결제/영수증
- 배송/상품/상품평
- 취소/반품/교환
- 이벤트/제휴/기타
- 제작가이드
- 디자인 파일
- 소량 제작
- 제작주의사항

상담 버튼:

- 상품문의하기: `index.html#quote`
- 자주묻는질문: `faq.html`
- 카톡상담: `index.html#quote`

비고:

- 실제 카카오톡 또는 ChannelTalk URL은 아직 확정되지 않았습니다.
- 카톡상담 링크는 운영 URL 확정 후 `perpackage-common.js`와 `support.html`에서 함께 교체해야 합니다.

## 4. 고객센터 연락처

현재 표시 연락처:

- `02-416-1540`

근거:

- 기존 `equipment.html` 안에서 확인된 번호를 사용했습니다.

운영 전 확인 필요:

- 실제 고객센터 대표번호로 계속 사용할지 확인해야 합니다.
- 운영 시간, 점심 시간, 휴무 문구도 실제 운영 기준 확인이 필요합니다.

- 마이쇼핑 바로가기
- 회원관리 안내

- 관심상품 페이지

## 7. Cafe24 스마트디자인 적용 시 주의할 점

- Cafe24 스킨 CSS가 정적 HTML의 스타일을 덮어쓸 수 있습니다.
- 실제 적용 후 computed style과 모바일 overflow를 다시 확인해야 합니다.
- 모듈 삽입 시 현재 카드 구조 안쪽만 교체하고, 바깥 레이아웃 클래스는 유지하는 편이 안전합니다.
- `support.html`의 주석 위치를 기준으로 Cafe24 모듈/변수를 넣으면 됩니다.
- 게시판 URL이 확정되기 전에는 현재처럼 `faq.html`, `blog.html`, `index.html#quote` 중심으로 유지합니다.

## 8. 직접 API로 구현하지 말아야 하는 이유

- 회원정보, 주문내역, 쿠폰, 적립금은 개인정보와 운영 데이터가 포함됩니다.
- 정적 홈페이지에서 별도 JS로 직접 구현하면 인증, 권한, 데이터 정합성 문제가 생길 수 있습니다.
- Cafe24는 스마트디자인 모듈과 마이쇼핑 변수를 제공하므로 해당 영역은 Cafe24 기능을 활용하는 방향이 적합합니다.
- 추후 운영 유지보수도 Cafe24 기본 흐름에 맞추는 편이 안전합니다.
