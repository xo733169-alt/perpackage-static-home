# 페르패키지 상품 흐름 QA 및 상품 상세/SEO 보강 보고

작성일: 2026-06-24

## 1. 작업 목적

페르패키지 홈페이지의 메인 → 카테고리 → 상품 상세 → 견적문의 흐름을 운영 전 QA 관점에서 점검하고, 상품 상세페이지 문구와 SEO 기본값을 보강했습니다.

이번 작업은 새 페이지를 대규모로 추가하는 것이 아니라, 이미 구현된 공용 카테고리/상품 상세/견적문의 흐름이 실제 운영 전에 안정적으로 이어지는지 확인하고 부족한 안내 문구를 정리하는 작업입니다.

## 2. 주요 점검 흐름

아래 흐름을 기준으로 코드와 데이터 구조를 점검했습니다.

- `index.html` → 단상자 카테고리 → 기본 흰색 단상자 상세 → 견적문의 CTA → `index.html#quote`
- 메인 검색창에서 로고 검색 → `category.html?search=로고` → 로고 관련 상품 → 상품 상세
- `category.html?category=shopping-bag&search=로고&print=로고인쇄상담` → 상품 상세 → 카테고리로 돌아가기
- 상품 상세 CTA → 견적문의 섹션 이동 시 선택 상품 안내 표시
- 상품 상세 FAQ/체크리스트/안내문구가 카테고리별로 분리되는지 확인
- 이미지 경로 누락 여부 확인
- 금지 문구 포함 여부 확인

## 3. 수정한 파일

### `index.html`

- 메인 페이지 SEO title을 더 명확하게 수정했습니다.
- 메인 페이지 meta description을 상품 탐색과 견적 상담 흐름 중심으로 정리했습니다.
- `#quote` 섹션에 선택 상품 안내가 표시되는 `data-quote-product-selected` 영역을 유지했습니다.

주요 위치:

- `<title>`: 6번째 줄
- `<meta name="description">`: 7번째 줄
- 선택 상품 안내 영역: 419번째 줄

### `category.html`

- 카테고리 상품목록 페이지의 기본 title/meta description을 정리했습니다.
- 실제 카테고리/검색어별 SEO는 `perpackage-category.js`에서 동적으로 처리하도록 유지했습니다.

### `perpackage-category.js`

- 검색어 또는 카테고리 상태에 따라 `document.title`이 동적으로 변경되도록 정리했습니다.
- meta description도 현재 검색어/카테고리에 맞춰 갱신되도록 보강했습니다.
- 필터/검색 상태에서 상세페이지로 이동할 때 `returnUrl`이 붙도록 확인했습니다.
- 검색어 초기화와 필터 상태 유지 흐름을 기존 구조와 충돌하지 않게 유지했습니다.

주요 위치:

- `metaDescription` 참조: 508번째 줄
- `returnUrl` 생성: 954~962번째 줄
- 동적 SEO 처리: 1000~1017번째 줄

### `product.html`

- 상품 상세페이지 기본 title/meta description 구조를 유지했습니다.
- 실제 상품별 title/meta description은 `perpackage-product.js`에서 동적으로 처리합니다.

### `perpackage-product.js`

- 카테고리별 상품 상세 안내문, 체크리스트, FAQ를 분리하는 `categoryContentGuide`를 추가했습니다.
- 상품 상세 데이터에 카테고리별 문구가 적용되도록 `applyProductContentGuide()`를 추가했습니다.
- 상품 상세 title/meta description을 상품명과 설명 기준으로 동적 변경하도록 보강했습니다.
- 상세 CTA가 `quoteProduct`, `quoteCategory` 값을 포함해 `index.html#quote`로 연결되도록 확인했습니다.
- `returnUrl`은 외부 URL이 들어가지 않도록 `category.html` 기준으로만 허용하는 구조를 유지했습니다.

주요 위치:

- `categoryContentGuide`: 64번째 줄
- `applyProductContentGuide()`: 855번째 줄
- 안전한 `returnUrl` 처리: 897번째 줄
- 견적문의 URL 생성: 912번째 줄
- 상품별 동적 SEO 처리: 1002~1039번째 줄

### `perpackage-main-renewal.js`

- 견적문의 섹션에서 선택 상품 안내를 더 자연스럽게 표시하도록 정리했습니다.
- `quoteProductLabels`에 등록된 상품이면 고객이 알아보기 쉬운 상품명으로 노출됩니다.
- 알 수 없는 상품 query가 들어온 경우에는 원문 slug를 그대로 보여주지 않고, “선택한 상품 정보 확인 필요” 안내로 처리합니다.

주요 위치:

- `quoteProductLabels`: 39번째 줄
- 선택 상품 안내 처리: 620~640번째 줄

## 4. 상품 상세 문구 보강 내용

상품 상세페이지에서 모든 카테고리가 같은 FAQ와 체크리스트를 반복하는 느낌을 줄이기 위해 카테고리별 안내를 분리했습니다.

적용된 카테고리:

- 단상자
- 택배박스
- 쇼핑백
- 봉투·슬리브
- 스티커·라벨
- 선물상자
- 샘플·소량
- 로고인쇄

각 카테고리별로 아래 항목이 다르게 적용됩니다.

- 안내 문구
- 상담 전 체크리스트
- 인쇄/제작 안내
- FAQ 질문과 답변

운영 목적은 고객이 상품 상세에서 바로 결정을 강요받는 느낌이 아니라, 필요한 정보를 확인하고 자연스럽게 견적문의로 넘어가게 하는 것입니다.

## 5. SEO 보강 내용

### 메인 페이지

기존보다 “기성 패키지·맞춤 패키지 제작 상담” 흐름이 드러나도록 title과 description을 정리했습니다.

### 카테고리 페이지

카테고리 또는 검색어에 따라 title/meta description이 동적으로 바뀝니다.

예시:

- 검색어가 있는 경우: `"검색어" 검색 결과 | 페르패키지`
- 일반 카테고리인 경우: `카테고리명 | 페르패키지`

### 상품 상세페이지

상품명 기준으로 title이 변경됩니다.

예시:

- `기본 흰색 단상자 | 페르패키지`
- `로고 인쇄 쇼핑백 | 페르패키지`

meta description은 상품 설명과 상담 흐름을 바탕으로 자동 생성됩니다.

## 6. 견적문의 선택 상품 안내

상품 상세페이지에서 견적문의 CTA를 누르면 아래 query가 붙습니다.

예시:

```text
index.html?quoteProduct=basic-white-box&quoteCategory=box#quote
```

`index.html#quote` 영역에서는 이 값을 읽어 선택 상품 안내를 표시합니다.

등록된 상품이면 고객이 읽기 쉬운 상품명으로 표시합니다.

예시:

```text
선택한 상품: 기본 흰색 단상자
아래 폼에 수량, 사이즈, 인쇄 여부를 남겨주시면 확인 후 상담을 도와드립니다.
```

등록되지 않은 값이면 상품 slug를 그대로 노출하지 않고 아래처럼 안내합니다.

```text
선택한 상품 정보 확인 필요
아래 폼에 원하시는 패키지 종류, 수량, 사이즈, 인쇄 여부를 남겨주세요.
```

## 8. 브라우저 QA 제한 사항

로컬 `file://` 페이지를 인앱 브라우저 자동화로 열어 PC/모바일 화면을 직접 검증하려 했으나, 브라우저 플러그인의 보안 정책으로 로컬 파일 접근이 차단되었습니다.

따라서 이번 검증은 아래 기준으로 진행했습니다.

- 파일 구조 검증
- JS 문법 검사
- 데이터 렌더링 구조 검사
- 링크 생성 로직 검사
- SEO 동적 처리 로직 검사
- 이미지 경로 검사
- 금지 문구 검사

실제 운영 전에는 브라우저에서 직접 아래 화면 확인이 필요합니다.

- PC 1440px
- 태블릿 768~820px
- 모바일 390px
- 실제 클릭 흐름
- 콘솔 오류
- 견적문의 iframe 표시 상태

## 9. 남은 작업

운영 전 추가로 진행하면 좋은 작업입니다.

1. 실제 브라우저에서 메인 → 카테고리 → 상품 상세 → 견적문의 흐름 클릭 QA
2. 모바일 390px에서 카드/상세 CTA/견적문의 iframe 가로 넘침 확인
3. 상품 상세페이지 이미지 품질 점검
4. 상품별 상세 설명을 실제 판매/상담 기준으로 더 구체화
5. 상품 상세페이지에 구조화 데이터 또는 OG 이미지 추가 검토
6. 플러그 iframe 안에서 선택 상품명이 자동 전달되는 방식이 가능한지 플러그 관리자 기능 확인

## 10. 다음 GPT에게 전달할 핵심 요약

페르패키지 홈페이지는 현재 `index.html` → `category.html` → `product.html` → `index.html#quote` 흐름으로 구성되어 있습니다.

이번 작업에서는 상품 상세페이지의 카테고리별 안내 문구와 FAQ를 분리했고, 메인/카테고리/상품 상세 SEO 기본값을 보강했습니다. 상품 상세에서 견적문의로 이동할 때 `quoteProduct`, `quoteCategory` query를 전달하며, 메인 견적문의 섹션에서는 선택 상품 안내를 표시합니다.

코드 검증 기준으로 JS 문법, 데이터 구조, 이미지 경로, 금지 문구, 상세 링크 생성은 정상입니다. 다만 브라우저 플러그인이 로컬 `file://` 자동 접근을 막아 실제 PC/모바일 화면 클릭 QA는 아직 수동 확인이 필요합니다.
